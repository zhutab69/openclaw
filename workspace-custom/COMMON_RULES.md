# COMMON_RULES.md - 所有 Agent 共用规则（核心）

> 所有 agent 启动时必须读取此文件。
> 长任务（>5分钟）额外加载 `COMMON_RULES_EXTENDED.md`。

## 🔴 优先级标签
- 🔴 **MUST** - 违反视为任务失败
- 🟡 **SHOULD** - 强烈建议

---

## 🔴 语言规则

**回复语言跟随 task 语言。** task 是中文则全程中文（含注释、日志）。混合语言以主体为准。

---

## 📖 技能调用标注 🔴 MUST

触发并读取 SKILL.md 执行时，输出开头加一行：`📖 调用技能：<name>（<中文简述>）`

### 技能匹配精确性 🔴 MUST

匹配**任务动作（动词）**而非关键词（名词）：
- "优化/修改X系统" → 代码任务，不触发相关 skill
- "用X系统生成报告" → 触发对应 skill
- "查今天天气" → 触发 weather skill

---

## ⚠️ PowerShell 🔴 MUST

`powershell -ExecutionPolicy Bypass -NoProfile -File "脚本路径"`

---

## 📢 通知文案 🔴 MUST

禁止：占位符 N/M/X、`[COORDINATED]`、Reply Tags `[[reply_to_current]]`。发前自检。

## 🧠 子 Agent Memory 🔴 MUST

子 agent MEMORY.md 只存领域知识，不存流程规则。不维护每日日记。

## 🌐 浏览器 🔴 MUST

任务结束关闭所有标签页。

## ✅ 任务完成性校验 🔴 MUST

文件生成→read验证 | 代码→语法检查 | 系统运行→退出码+预期输出。失败立即报告。

---

## 📂 文件存储 🔴 MUST

临时文件→agent workspace | 最终交付→`C:\Users\zhuyulin\.openclaw\workspace\` | 图片→`~/.openclaw/`

---

## 📊 通知规则 🔴 MUST

**一个任务链只有一个通知者。**
- `[COORDINATED]` → 静默 | 独立任务 → 自己通知
- <2分钟不发 | >5分钟必发
- 进度→wecom | 交付→并行双通道

**R2 过程通知（替代事前请示）🔴：** 每完成一个 R2 动作后立即发一条 wecom 通知，格式：
```
✅ 已执行：<一句话动作>
变更：<文件/命令清单，≤5行>
验证：<退出码/read确认/测试结果>
回滚：<还原命令或备份路径>
```
多个 R2 动作属于同一任务链时可合并成一条，但必须在任务结束前发出，不能只在最终总结里带过。

优先国内生态。默认中文、北京时间。

## ❗ 目标不降级 🔴 MUST

子 agent 失败时不缩小范围假装完成。允许分步、换方案，禁止降标。

---

## 🔄 Gateway 重启 🔴 MUST

多个修改攒一起重启。能热生效的不重启。

---

## ⚡ 自主执行与风险分级 🔴 MUST

默认偏向直接执行，只在 R3 停下来等确认。

| 级别 | 特征 | 行为 |
|------|------|------|
| R1 低风险·可逆 | 读文件、查询、分析、只读命令、临时文件、加注释 | 直接做，不通知 |
| R2 中风险·可回滚 | 改代码/配置/规则（先备份）、装依赖、改 cron、重启 Gateway、跑写入型脚本 | 直接做，做完发过程通知（变更清单+验证结果+回滚方式） |
| R3 高风险·难回滚 | 删多文件/目录、删库或 >1GB 数据文件、对外发布（发消息给他人/群发/公开）、生产变更、资金或账号权限、无法备份的不可逆操作、单次影响 >50 文件 | 先说清影响+回滚方案，等用户明确同意 |

口诀：「做错了能不能一条命令还原？」能→直接做；不能→先问。

**方案选择：** R1/R2 自己选最优方案执行，通知里一句话说明为什么选它；R3 给 2-3 个方案等用户选。

**仍需先问的唯一例外：** 需求本身有歧义（目标不明、可能理解反了）——这是意图不明，不是风险问题。能用工具查清的事自己查，不要拿去问用户。
